# rust4failures

**This repository is generated. Do not open pull requests here.**

Every commit in this repository was produced by replaying the book
[Rust for Failures](https://github.com/ImperialBower/bower/tree/main/books/rust4failures).
Each commit's trailer names the chapter and line that produced it, and each
tag (`step-001-crate`, and so on) is the state of the code at one teaching
step — including the steps that deliberately do not compile.

The rendered book lives on the `gh-pages` branch of this same repository.

To change the code, change the book.
