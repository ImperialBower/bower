# Init

One of the many reasons that I love Rust are the tools, which are the best in the business. 
The one we will introduce in this
chapter is [cargo](https://doc.rust-lang.org/cargo/). It's Rust's package manager and build tool, 
similar to [pip](https://pypi.org/project/pip/) in Python or [npm](https://www.npmjs.com/) in
JavaScript.

So let's create our project. 

```shell
#> cargo new rust4failures --lib
```

This creates four files:

```shell
.gitignore
Cargo.lock
Cargo.toml
src/lib.rs
```

## Those comment lines

Two of the blocks above end with a pair of comments that `cargo new` did not
write:

```text
# bower:begin dev-dependencies
# bower:end dev-dependencies
```

They are *region markers*. They mark a hole that a later chapter fills — the
test framework lands in that one, and `src/lib.rs` has another called `mods`
where modules will be declared. They are stripped out before the file reaches
the repository, so the `Cargo.toml` you can check out is exactly the one cargo
made.
